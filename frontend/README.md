📌 Sobre o Projeto

O Dashboard é uma aplicação web full stack desenvolvida para gerenciamento e visualização de dados em um painel administrativo moderno e responsivo.

O projeto é dividido em duas partes principais:

⚙️ Backend → responsável pela API, regras de negócio e integração de dados

🎨 Frontend → interface do usuário com dashboard interativo

📊 Dashboard Full Stack

Sistema de dashboard moderno desenvolvido com React + TypeScript no frontend e Node.js no backend, focado em performance, organização e escalabilidade.

A interface utiliza Radix UI para criação de componentes acessíveis, consistentes e altamente reutilizáveis.
